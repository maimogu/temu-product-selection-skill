# amazon-profit-calc — FBA 利润计算子 Skill

## 职责

基于产品规格和 Amazon FBA 费率表，计算预估利润、利润率、盈亏平衡点。

## 触发条件

- 用户说"计算利润"、"FBA 费用"、"利润分析"、"profit calc"
- 飞书自动化 Webhook 触发（BSR 采集完成后）

## 前置条件

- 飞书多维表格「商品详情」表已有数据（含价格信息）
- 飞书多维表格「利润分析」表已创建
- 无需外部 API（仅依赖内置费率表）

## 工作流

```
输入：商品 ASIN 列表（含价格/重量/尺寸/品类）
       │
       ▼
 Step 1: 费率匹配
   - 配送费：按产品尺寸重量匹配费率段
   - 佣金：按品类匹配百分比
   - 仓储费：按月估算
   - 参考：config/fba_rates.yaml
       │
       ▼
 Step 2: 费用计算
   - 配送费 + 佣金 + 仓储费 + 广告费 + 头程物流
   - 广告费 = 售价 × 默认 ACoS (20%)
   - 头程物流 = 售价 × 8%（可配置）
       │
       ▼
 Step 3: 利润分析
   - 净利润 = 售价 - 采购成本 - 总费用
   - 利润率 = 净利润 / 售价
   - 是否达标：利润率 ≥ 15%
       │
       ▼
 Step 4: 写入飞书
   - 飞书多维表格「利润分析」表
   - 字段：ASIN、售价、FBA费用、佣金、净利润、利润率、是否达标
```

## 使用方式

```bash
bash bootstrap.sh profit
```

## 输出

- 飞书多维表格「利润分析」表中新增记录
- 控制台输出利润率摘要

## 费率表说明

费率表数据来源为 Amazon Seller Central 公开费率（美国站），存储在 `config/fba_rates.yaml`。

| 费用项 | 说明 | 计算方式 |
|---|---|---|
| 配送费 | Amazon FBA 配送费 | 按尺寸段 + 重量计算 |
| 销售佣金 | 按品类百分比 | 售价 × 品类费率，最低 $0.30 |
| 仓储费 | 月度仓储费 | 体积(立方英尺) × $0.78/月 |
| 广告费 | 预估广告花费 | 售价 × 20% (默认 ACoS) |
| 头程物流 | 预估海运/空运费 | 售价 × 8% |

## 品类支持

| 品类 | 佣金率 |
|---|---|
| 电子产品 | 8% |
| 电脑 | 6% |
| 家居/厨房 | 15% |
| 运动/户外 | 15% |
| 玩具 | 15% |
| 美妆 | 15% |
| 服装 | 17% |
| 珠宝 | 20% |
| 其他 | 15% (默认) |

## 配置

- [config/fba_rates.yaml](../../config/fba_rates.yaml) — 费率表 + 默认参数
- 费率变更时更新 YAML 文件即可，无需改代码

## 错误处理

| 场景 | 处理 |
|---|---|
| 商品缺少价格/重量/尺寸 | 使用默认值估算，标记为"估算" |
| 品类不在费率表中 | 使用默认佣金率 15% |
| 飞书 API 429 | 指数退避重试 3 次 |
