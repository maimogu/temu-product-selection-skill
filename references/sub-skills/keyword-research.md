# amazon-keyword-research — 关键词调研子 Skill

## 职责

对指定类目进行关键词采集与 8 维智能分类，生成关键词库和广告投放建议。

## 触发条件

- 用户说"分析关键词"、"关键词调研"、"keyword research"
- 飞书自动化 Webhook 触发（类目采集完成后）

## 前置条件

- 飞书多维表格「类目管理」表已配置
- 飞书多维表格「关键词库」表已创建
- 环境变量 `KEEPA_API_KEY` 已配置（keepa-mcp 采集需要）

## 工作流

```
输入：类目名称 / 种子关键词
       │
       ▼
 Step 1: 关键词采集
   - keepa-mcp 关键词搜索（主力）
   - Amazon 搜索框自动补全（agent-browser 兜底）
   - 目标：500+ 关键词
       │
       ▼
 Step 2: 8 维智能分类
   - 否定词 / 品牌词 / 材质词 / 场景词
   - 属性词 / 功能词 / 核心词 / 其他
   - 规则引擎：config/keyword_categories.yaml
       │
       ▼
 Step 3: 竞争度评估
   - 搜索量级估算（1-5）
   - 竞争度估算（1-5）
   - 季节性检测
       │
       ▼
 Step 4: 广告分组建议
   - 否定词清单
   - 精准匹配组（品牌词 + 核心词）
   - 广泛匹配组（功能词 + 属性词）
   - 场景广告组
       │
       ▼
 Step 5: 写入飞书
   - 飞书多维表格「关键词库」表
   - 字段：关键词、分类标签、搜索量级、竞争度、季节性
```

## 使用方式

```bash
bash bootstrap.sh keywords
```

## 输出

- 飞书多维表格「关键词库」表中新增记录
- 控制台输出广告分组建议摘要

## 配置

- [config/keyword_categories.yaml](../../config/keyword_categories.yaml) — 8 维分类规则
- 修改分类规则或新增品牌后无需改代码，下次运行自动生效

## 错误处理

| 场景 | 处理 |
|---|---|
| keepa-mcp 不可用 | 降级为 agent-browser 自动补全采集 |
| 飞书 API 429 | 指数退避重试 3 次 |
| 关键词匹配不到任何分类 | 归入"其他"分类 |
| 关键词库表已有记录 | 写入前先清空，避免重复 |
