# 亚马逊站内类目热卖二阶选品法 — 数据指标体系设计文档

**日期:** 2026-07-20
**状态:** 已确认

## 1. 概述

### 1.1 目标

构建一套基于"二阶选品法"的亚马逊选品数据指标体系工具。以飞书多维表格为中心枢纽，通过 Python 脚本采集 Amazon Best Sellers 榜单数据，计算五维指标综合得分，并在飞书多维表格中展示与告警。

### 1.2 北极星指标

类目月销量（或销售额）—— 决定选品成败的核心目标。

### 1.3 指标体系

| 一级指标 | 权重 | 二级指标（第一期可用） | 三级指标（二期） |
|---|---|---|---|
| 流量 | 25% | 类目排名、排名稳定性、出现频率 | 搜索曝光UV、关键词排名 |
| 转化率 | 25% | 星级评分、评论量级、评论增长 | 加购率、退货率、页面深度 |
| 客单价 | 20% | 价格分、价格趋势 | 高单价占比、组合销售系数 |
| 新品成长性 | 20% | 销量增速、排名提升、生命周期 | 广告投放强度、上新月数 |
| 侵权风险 | 10% | 品牌风险匹配 | 商标检索、外观相似度、供应商合规 |

### 1.4 技术栈

- **语言**: Python 3.10+
- **数据采集**: keepa-mcp（主力）+ agent-browser（兜底）+ Apify（按需）
- **数据存储**: 飞书多维表格（Base API）
- **前端展示**: 飞书多维表格视图 + 仪表盘
- **调度与告警**: 飞书自动化流程
- **测试**: pytest

## 4. 指标计算逻辑

### 4.1 流量得分（权重 25%）

```
排名分 = (1 - 当前BSR排名 / 100) × 100
排名稳定性 = 1 - (排名标准差 / 排名均值)
出现频率 = (该ASIN出现次数 / 总快照次数) × 100
流量得分 = 排名分 × 0.5 + 排名稳定性 × 0.3 + 出现频率 × 0.2
```

### 4.2 转化得分（权重 25%）

```
评分分 = 星级评分 × 20
评论量级分 = min(评论数 / 500, 1) × 100
评分成长期 = (最新评论数 - 最早评论数) / max(最早评论数, 1) × 100
转化得分 = 评分分 × 0.4 + 评论量级分 × 0.4 + 评分成长期 × 0.2
```

### 4.3 客单价得分（权重 20%）

```
价格分 = 基于价格在类目均价区间的归一化（0.5-2倍均价最优）
价格趋势 = 最近价格 / 首期价格
客单价得分 = 价格分 × 0.6 + 价格趋势 × 0.4
```

### 4.4 成长性得分（权重 20%）

```
销量增速 = (最近销量 - 首期销量) / max(首期销量, 1)
排名提升 = 首期排名 - 当前排名
生命周期 = 1 - min(上新月数 / 12, 1)
成长性得分 = 销量增速归一化 × 0.4 + 排名提升归一化 × 0.4 + 生命周期 × 0.2
```

### 4.5 风险得分（权重 10%）

```
品牌在风险名单中 → 0
品牌为空 → 70
其他 → 100
```

### 4.6 综合得分

```
综合得分 = 流量×0.25 + 转化×0.25 + 客单价×0.20 + 成长性×0.20 + 风险×0.10
```

权重通过 `config/scoring.yaml` 可配置。

## 5. 采集流程

### 5.1 双通道

- 通道 A（主力）：keepa-mcp → get_best_sellers + get_product
- 通道 B（兜底）：agent-browser → 直接访问 Amazon Best Sellers 页面解析

### 5.2 调度

飞书自动化「定时触发」→ 每周一 09:00 → Webhook → crawl.py → 写入多维表格
飞书自动化「定时触发」→ 每周一 10:00 → Webhook → metrics.py → 写入指标得分

## 6. 告警机制

3 个飞书自动化流程：

| 流程 | 触发条件 | 动作 |
|---|---|---|
| 侵权风险告警 | 指标得分表新增记录，风险得分<30 | 发送飞书消息给法务/采购 |
| 采集失败告警 | Webhook 接收（脚本失败时 POST） | 发送飞书消息通知运营 |
| 高风险复查 | 定时触发，每周一 10:30 | 查找综合得分>70且风险<50，发送消息 |

## 7. 错误处理

| 情况 | 处理 |
|---|---|
| keepa-mcp 不可用 | 降级到 agent-browser |
| 榜单页返回空 | 跳过该类目，不影响其他 |
| 某 ASIN 详情失败 | 部分字段为空，标记数据不完整 |
| 飞书 API 429 | 指数退避重试 3 次 |
| ASIN 仅 1 条快照 | 排名稳定性和评分成长期赋默认值 50 |
| 价格为 0 或异常 | 剔除该条记录 |
| 品牌缺失 | 风险得分=70 |
