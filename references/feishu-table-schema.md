# 飞书多维表格结构定义

本 Skill 使用一个飞书多维表格 Base，包含 6 张数据表。所有表的字段名（中文）必须严格匹配，否则 Python 脚本无法正确读写。

## 表 1: 类目管理（categories）

| 字段名 | 字段类型 | 必填 | 说明 |
|---|---|---|---|
| 类目名称 | 文本 | 是 | 如 "Kitchen & Dining" |
| 抓取URL | 链接 | 是 | Amazon Best Sellers 类目 URL |
| 是否启用 | 复选框 | 否 | 默认未勾选；勾选后才会被采集 |
| 创建时间 | 创建时间 | 否 | 自动生成 |

**示例 URL 格式**：
- `https://www.amazon.com/Best-Sellers-Kitchen-Dining/zgbss/kitchen/ref=zg_bs_nav_kitchen_0`
- `https://www.amazon.com/gp/bestsellers/kitchen/13801`

URL 中必须包含数字类目 ID（Amazon browseNode），用于 keepa-mcp 的 `category_id` 参数。

## 表 2: 榜单快照（snapshots + rankings）

每次采集追加 100 条记录（一个类目的 Top100）。

| 字段名 | 字段类型 | 说明 |
|---|---|---|
| 快照日期 | 日期 | 采集日期 |
| 类目名称 | 单选/文本 | 关联类目管理表 |
| 排名 | 数字 | BSR 排名 1-100 |
| ASIN | 文本 | 商品唯一标识 |
| 商品标题 | 文本 | 抓取时的标题 |
| 价格 | 货币 | 抓取时价格（USD） |
| 星级评分 | 数字 | 0-5，保留 2 位小数 |
| Review数量 | 数字 | 整数 |
| 估算销量 | 数字 | 基于排名的估算（可空） |
| 估算销售额 | 货币 | 价格 × 估算销量（可空） |
| 供应商信息 | 多行文本 | 供应商/品牌名 |
| 详情页链接 | 链接 | 商品详情 URL |

## 表 3: 商品详情（products）

按 ASIN 去重的商品最新状态。脚本采用 upsert 模式：已存在的 ASIN 更新字段，不存在的 ASIN 新增。

| 字段名 | 字段类型 | 说明 |
|---|---|---|
| ASIN | 文本 | 唯一标识 |
| 商品标题 | 文本 | 最新标题 |
| 品牌 | 文本 | 品牌名 |
| 当前价格 | 货币 | 最新价格 |
| 星级评分 | 数字 | 0-5 |
| Review数量 | 数字 | 整数 |
| 供应商信息 | 多行文本 | 供应商 |
| 详情页链接 | 链接 | 商品详情 URL |
| 首次收录 | 创建时间 | 自动 |
| 最近更新 | 修改时间 | 自动 |

## 表 4: 指标得分（product_metrics）

每次运行 `metrics.py` 会**先清空再写入**，避免历史记录堆积。

| 字段名 | 字段类型 | 说明 |
|---|---|---|
| ASIN | 文本 | 关联商品详情表 |
| 计算时间 | 日期 | 指标计算时间 |
| 流量得分 | 数字 | 0-100 |
| 转化得分 | 数字 | 0-100 |
| 客单价得分 | 数字 | 0-100 |
| 成长性得分 | 数字 | 0-100 |
| 风险得分 | 数字 | 0-100（越高越安全） |
| 综合得分 | 数字 | 0-100 |
| 指标明细JSON | 多行文本 | 完整 JSON 备查 |

## 视图与仪表盘建议

- **榜单快照** → 表格视图，按"快照日期"分组，按"排名"升序
- **商品详情** → 画廊视图（卡片样式）+ 表格视图
- **指标得分** → 表格视图，按"综合得分"降序，加颜色条件格式：
  - 绿色：综合得分 ≥ 80
  - 黄色：50 ≤ 综合得分 < 80
  - 红色：综合得分 < 50 或 风险得分 < 30
- **关键词库** → 表格视图，按"分类标签"分组，按"搜索量级"降序
- **利润分析** → 表格视图，按"利润率"降序，绿色高亮利润率≥15%
- **仪表盘** → 统计卡片（监控类目数、商品总数、本周新增）+ 综合得分趋势图 + Top10 商品排行

## 表 5: 关键词库（keywords）

| 字段名 | 字段类型 | 说明 |
|---|---|---|
| 关键词 | 文本 | 关键词文本 |

## 表 6: 利润分析（profit_analysis）

| 字段名 | 字段类型 | 说明 |
|---|---|---|
| ASIN | 文本 | 关联商品详情表 |
| 售价 | 货币 | 商品售价（USD） |
| 采购成本 | 货币 | 采购成本（USD） |
| 配送费 | 货币 | FBA 配送费 |
| 佣金 | 货币 | 销售佣金 |
| 仓储费 | 货币 | 月度仓储费 |
| 广告费 | 货币 | 预估广告费 |
| 头程物流 | 货币 | 预估头程物流费 |
| 总费用 | 货币 | 所有费用合计 |
| 净利润 | 货币 | 售价 - 采购成本 - 总费用 |
| 利润率 | 数字 | 净利润 / 售价 |
| 盈亏平衡月销量 | 数字 | 至少需卖出多少件才能盈利 |
| 是否达标 | 文本 | "是" / "否"（利润率 ≥ 15%） |

## 字段类型说明

飞书多维表格字段在 API 中的返回结构：

| 字段类型 | API 返回格式 |
|---|---|
| 文本 | 字符串 或 `{"text": "..."}` |
| 数字 | 数字 或 `{"value": 123, "text": "..."}` |
| 货币 | 数字 或 `{"value": 29.99, "text": "$29.99"}` |
| 复选框 | `true` / `false` |
| 日期 | 毫秒时间戳（int） 或 ISO 字符串 |
| 链接 | `{"link": "https://...", "text": "..."}` 或 None |
| 关联 | `[{"text": "...", "record_ids": [...]}]` 或 `None` |

Python 脚本（`metrics.py`、`crawl.py`）已对上述所有结构做兼容处理。
