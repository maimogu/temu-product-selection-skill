# 五维指标评分公式

## 综合得分权重

权重在 [config/scoring.yaml](../config/scoring.yaml) 中配置，修改后下次运行 `metrics.py` 自动生效。

```yaml
weights:
  traffic: 0.25      # 流量得分权重
  conversion: 0.25   # 转化得分权重
  aov: 0.20          # 客单价得分权重
  growth: 0.20       # 成长性得分权重
  risk: 0.10         # 风险得分权重
```

**综合得分公式**：

```
综合得分 = 流量×0.25 + 转化×0.25 + 客单价×0.20 + 成长性×0.20 + 风险×0.10
```

---

## 1. 流量得分（权重 25%）

基于榜单快照历史数据推断，3 个子指标加权：

```
排名分 = (1 - 当前BSR排名 / 100) × 100
排名稳定性 = (1 - 排名标准差 / 排名均值) × 100
出现频率 = (该ASIN出现次数 / 类目总快照次数) × 100

流量得分 = 排名分 × 0.5 + 排名稳定性 × 0.3 + 出现频率 × 0.2
```

**边界情况**：
- 仅 1 条快照 → 排名稳定性默认 50
- 排名标准差为 0（所有快照排名相同）→ 排名稳定性默认 50
- 空记录 → 返回 0

---

## 2. 转化得分（权重 25%）

基于星级评分和评论数推断：

```
评分分 = 星级评分 × 20              # 5星=100, 4星=80
评论量级分 = min(评论数 / 500, 1) × 100   # 评论数 500 封顶
评分成长期 = (最新评论数 - 最早评论数) / max(最早评论数, 1) × 100

转化得分 = 评分分 × 0.4 + 评论量级分 × 0.4 + 评分成长期 × 0.2
```

**边界情况**：
- 最早评论数为 0 → 评分成长期默认 50（仅 1 条记录时为 0）
- 空记录 → 返回 0

---

## 3. 客单价得分（权重 20%）

```
价格比 = 最新价格 / 类目均价
价格分:
  - 比值在 [0.5, 2.0] 区间: 100 - |比值-1| × 50  （越接近均价分越高）
  - 比值偏离 [0.5, 2.0]: 100 - |比值-1| × 60      （偏离越远扣分越重）

价格趋势 = 最新价格 / 首期价格
趋势分:
  - 比值在 [0.9, 1.2]: 100                         （涨价 0-20% 最优）
  - 比值 > 1.2: 100 - (比值-1.2) × 100             （暴涨扣分）
  - 比值 < 0.9: 100 - (1-比值) × 200               （降价扣分更重）

客单价得分 = 价格分 × 0.6 + 趋势分 × 0.4
```

**边界情况**：
- 类目均价为 0 或负数 → 返回默认值 50
- 仅 1 条记录 → 价格趋势默认 1.0
- 空记录 → 返回默认值 50

---

## 4. 成长性得分（权重 20%）

```
销量增速 = (最新销量 - 首期销量) / max(首期销量, 1)
销量增速归一化 = clamp((销量增速 + 0.5) × 50, 0, 100)
  # 增长 0% → 25 分；增长 100% → 75 分；增长 150% → 100 分

排名提升 = 首期排名 - 当前排名
排名提升归一化 = clamp((排名提升 + 10) × 5, 0, 100)
  # 提升超过 10 位 → 100 分；不变 → 50 分；下降 10 位 → 0 分

生命周期 = 1 - min(快照次数 / 12, 1)
生命周期得分 = 生命周期 × 100
  # 首次出现 → 100 分；出现满 12 次 → 0 分

成长性得分 = 销量增速归一化 × 0.4 + 排名提升归一化 × 0.4 + 生命周期得分 × 0.2
```

**边界情况**：
- 空记录 → 返回 0

---

## 5. 风险得分（权重 10%）

基于品牌名匹配高风险品牌名单（在 `config/scoring.yaml` 的 `thresholds.high_risk_brands` 中配置）：

```
品牌在风险名单中（大小写不敏感） → 0
品牌为空或纯空格 → 70
其他 → 100
```

**注意**：风险得分越高越安全（与"分数高=好"的语义一致）。

---

## 计算流程

```
Python 脚本（metrics.py）
  ↓
1. 读取飞书「榜单快照」表所有记录
2. 过滤价格 ≤ 0 的异常记录
3. 按 ASIN 聚合，记录每个 ASIN 所属类目
4. 按类目分别计算：
   - 类目总快照次数（用于"出现频率"）
   - 类目均价（用于"客单价得分"）
5. 对每个 ASIN 调用 compute_metrics():
   - 计算 5 个维度得分
   - 加权求和得到综合得分
6. 按综合得分降序排序
7. 清空「指标得分」表旧记录
8. 批量写入新记录
```

---

## 第一期限制

第一期只用榜单页面能稳定获取的字段（排名、价格、评分、评论数、品牌）。以下二级/三级指标需要详情页采集，留到第二期：

| 一级指标 | 二期可补充字段 |
|---|---|
| 流量 | 搜索曝光UV、关键词排名、广告位 |
| 转化 | 加购率、退货率、页面浏览深度、客服介入率 |
| 客单价 | 高单价商品占比、组合销售系数 |
| 成长性 | 广告投放强度、上新月数 |
| 风险 | 商标检索得分、外观相似度、供应商合规评分 |

公式扩展时只需修改 `scripts/scoring.py` 中的对应函数，无需改架构。
